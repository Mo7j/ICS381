# ICS381 - Principles of Artificial Intelligence

Coursework and implementations for ICS381 at KFUPM.  
This repository covers core AI concepts including intelligent agents, search algorithms, constraint satisfaction problems, probabilistic reasoning, adversarial search, and introductory machine learning.

## Topics Covered
- Intelligent Agents
- BFS, DFS, UCS, A*
- Heuristic & Local Search
- Constraint Satisfaction Problems (CSP)
- Adversarial Search & Minimax
- Bayesian Networks
- Knowledge-Based Systems
- Introductory Machine Learning
- Natural Language Processing Basics

## Technologies
- Python
- Jupyter Notebook

## Note
This repository contains course assignments, practice problems, and AI-related implementations developed throughout the semester.
